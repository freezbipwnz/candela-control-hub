## ✨ Ключевые возможности

### 1. Двойной режим работы (Dual-Mode Interface)
* **📱 Telegram Mini App Mode (до 430px):** Компактный эргономичный вид внутри Telegram на iOS/Android (управление в 1–2 тапа, нижний навигационный таб-бар, поддержка свайпов, тактильный отклик Telegram Haptics).
* **💻 Desktop & Tablet CRM (768px – 1920px):** Полноценная CRM-панель для широких мониторов (сворачиваемый боковой сайдбар, плотные таблицы данных, модальные окна, детальные графики).

### 2. Дизайн-система «Warm Quiet Luxury & Modern Minimalist»
* **Палитра Candela Atelier:** Тёплый терракотовый (`#B8683D`), глубокий графит (`#141211`), камень (`#1C1917` / `#24201D`), слоновая кость (`#FBF9F5`) и янтарь (`#D97706`).
* **Типографика:** Элегантный *Cormorant Garamond* для акцентных заголовков и метрик + выверенный *Plus Jakarta Sans* для интерфейса и таблиц.

### 3. Ролевая модель доступа (RBAC)
Переключение ролей на лету для тестирования сценариев доступа:
* **👑 Владелец (Owner):** 100% доступ (включая финансовую аналитику, управление сотрудниками, удаление).
* **💼 Управляющий (Admin):** Заказы, Склад, Каталог, Маркетинг, Отзывы.
* **📦 Сборщик / Логист (Manager):** Заказы (сборка, ввод трек-номеров СДЭК) и остатки на складе.
* **✍️ Контент-менеджер (Editor):** Каталог (пирамиды ароматов, медиа) и ответы на отзывы.

## 🧭 Модули системы

1. **📊 Дашборд и Финансовая Аналитика:** Выручка (₽), чистая прибыль, средний чек (AOV), динамика продаж (интерактивный график), структура категорий, топ-5 ароматов-бестселлеров.
2. **📦 Управление заказами:** Табличный и карточный вид, фильтрация по статусам, детальная карточка заказа, прикрепление трек-номеров СДЭК/Почты с моментальным уведомлением клиента в Telegram, печать комплектовочного листа.
3. **🕯️ Каталог товаров:** Матрица продукции, мгновенный переключатель видимости (Active/Hidden), конструктор ольфакторной пирамиды (Top, Heart, Base ноты), вариации объемов (100 / 250 мл).
4. **🏢 Контроль остатков и Склад:** Матрица остатков с inline-редактированием на лету, система критических алертов Low Stock Alert (`< 5 шт`), журнал списаний.
5. **🏷️ Маркетинг и Промокоды:** Генератор промокодов (% и фикс скидка, пороги корзины, лимиты активаций), баннер-менеджер витрины.
6. **⭐ Отзывы и Модерация:** Модерация оценок покупателей, подтвержденные покупки, публикация официального ответа от лица бренда с золотым бейджем.
7. **👥 Управление персоналом:** Добавление сотрудников по Telegram ID, распределение ролей и прав доступа.

## 🚀 Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/freezbipwnz/candela-control-hub.git

# Переход в папку
cd candela-control-hub

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

Локальный сервер запустится по адресу: `http://localhost:3000`

```bash
# Сборка production-бандла
npm run build
```
